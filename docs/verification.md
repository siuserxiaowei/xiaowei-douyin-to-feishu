# 验证记录

日期：2026-09-24。对象：`xiaowei-douyin-to-feishu` v1.0.1。

## 真实运行

在已安装本技能的豆包工作环境中，一条公开视频经浏览器会话、`yt-dlp`、mediakit Cloud ASR 取得 142 段逐字稿，覆盖视频开头至结尾，共 1241 字。第一次运行在本地稿件处停下；随后使用该次运行记录在飞书创建文档，并回读逐字稿全文，与本地原稿一致。ASR 结果**未经过人工逐字校对**。

针对 v1.0.1 的新路径，另用相同视频在线执行 `yt-dlp` 元数据查询，返回正确视频 ID 和可用媒体格式；执行 `audio_fallback.py download --cookies-from-browser chrome`，成功生成 7,177,178 字节的 WAV 音轨。临时验证文件已自动清理。

新增的 `publish_feishu.py` 对已有 `run.json` 和真实飞书文档执行了续跑：只发起全文读取，没有重复创建，输出 `verified_full_text`、1241 字。已保存的飞书回读结果也被离线解析并与原稿逐字核对。

## 边界

这是一条真实视频在当前账号和浏览器会话里的成功记录，不保证所有抖音视频或环境均可获取。尚未实测批量处理、主页采集、追加到已有文档、豆包内置 `web.fetch`、飞书妙记或本地 SenseVoice。语音识别文本可能有同音字及断句错误；“全文读回一致”验证的是飞书保存未丢字，不代表口播与识别结果逐字准确。

v1.0.0 的 21 项离线测试与 dry-run 记录保留在 [v1.0.0 发布说明](release-v1.0.0.md)；其发行包不变。
