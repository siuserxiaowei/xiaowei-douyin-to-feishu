# v1.0.0 · 抖音逐字稿存飞书

首个版本，面向豆包工作：从抖音分享链接、视频链接或博主主页获取完整口播，保留来源，整理后保存为飞书云文档。

- 默认新建飞书文档，也可向用户指定的文档追加，按视频 ID 避免重复写入。
- 逐字稿保留原话，简短速览单独标注为 AI 提炼。
- 优先使用豆包工作内置取稿能力，失败后尝试已有视频转写或飞书妙记。
- 附可选的分享页音频提取和本地 SenseVoice 转写脚本。
- 提供保真 Markdown 生成、全文状态区分和写入后读回核验指引。

下载资产中的 `xiaowei-douyin-to-feishu-v1.0.0.zip`，交给豆包工作读取、安装整个技能文件夹。安装和调用提示词见仓库 README。

验证：21 项本地测试通过，实际 FFmpeg 合成音频提取、CommonMark 正文保留检查、Skill 格式校验和飞书 CLI dry-run 通过。线上链路尚未验收，请先用一条真实公开视频在豆包工作中完成取稿、写入和读回。

第三方来源与 Chubby 的 MIT 许可已保留。`SHA256SUMS.txt` 可用于核对下载包。
