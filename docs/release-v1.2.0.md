# v1.2.0 · 增加专业术语复核

ASR 回退此前只负责取得并拼接字幕，没有单独检查同音误识、产品/模型名、人名、缩写和数字单位。本版在口播取回后增加术语候选扫描、证据核对和修订记录流程。

- 保留 `transcript_asr_raw.txt`，确认有证据时才在 `transcript.txt` 中局部改词；不确定项保留原识别词并标为待核实。
- 结合 ASR 时间戳定位可疑片段，优先用音频回听、用户术语表或官方名称资料确认；记录时间点、候选词、决定、依据和置信度。
- 校订后同步更新稿件字数与 SHA-256，确保飞书保存的版本与最终稿一致。
- 明确该流程是术语专项复核，不是新 ASR 引擎或独立术语词库；尚未在术语密集视频上做真实准确率验证。

参考上游公开的抖音取稿说明，本版补的是我们实际 ASR 回退缺少的复核步骤。上游说明中没有公开独立术语词库或术语校正模块。

下载 `xiaowei-douyin-to-feishu-v1.2.0.zip` 并导入整个技能文件夹。第一次试用建议提供视频链接和已知的专业术语、人名拼写，并要求只测试提取、不创建飞书文档；未确认词会单独列出，不会擅自按语意改顺。
