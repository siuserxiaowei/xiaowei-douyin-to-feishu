# 小伟的抖音逐字稿存飞书

这是面向豆包工作的 Skill 包。接收抖音链接，取回完整口播，附来源和简短速览，保存为飞书云文档。

## 放进豆包工作

将 [v1.0.0 技能包](../dist/xiaowei-douyin-to-feishu-v1.0.0.zip) 交给豆包工作。可以直接使用下面这段话：

> 请解压这个技能包，阅读 xiaowei-douyin-to-feishu/SKILL.md，并按当前豆包工作支持的方式安装。保留 references、scripts 和 licenses，确保相对路径有效。它用于把抖音逐字稿存到飞书云文档。安装时先检查可用工具，不下载视频、不新建飞书文档、不自动安装本地语音模型。完成后告诉我实际安装位置，以及内置取稿和飞书文档能力是否可用。

不同版本的豆包工作可能提供不同的安装入口；如果不能从附件安装，可以解压后导入整个技能文件夹。不要只复制 SKILL.md 丢掉配套文件。

## 第一次调用

把下面的“链接”替换成你自己的真实公开抖音链接：

> 用“抖音逐字稿存飞书”处理这个链接：链接。取完整口播，保留原话，附 3 条以内的内容速览，保存为一篇新的飞书文档。完成后读回检查，给我文档链接和缺失情况。

如果要放进已有文档：

> 把这些抖音视频的完整逐字稿追加到这篇飞书文档：文档链接。已有的视频不要重复写，保留原有内容。

如果只要逐字稿：

> 把这个抖音转成逐字稿存到飞书，只保留原文和来源，不加内容速览。

建议第一次用 1 条视频跑通“取稿 → 写入 → 读回”，再处理多条或博主主页。用户未指定主页采集数量时，默认最近 5 条；无法确认发布时间顺序时会说明范围。

## 按我们的方式改了什么

| 原方案 / 参考点 | 这一版 |
|---|---|
| 主要围绕多维表格字段采集 | 改为能直接阅读的飞书云文档，长逐字稿按章节排版 |
| 没给表格地址就先询问 | 默认新建文档；指定已有文档则追加 |
| 固定选题标签和主题总结 | 改为简短内容速览，标记 AI 提炼；只要原文时省略 |
| 标题与口播靠第一个空行分开 | 根据真实工具结构识别，避免把简介当逐字稿 |
| 小于 50 字或没有结束标点即失败 | 改为疑点检查，承认短口播和自然停顿 |
| 第二个项目的移动分享页下载 | 加入可选音频提取脚本，内置能力失效时备用 |
| 第二个项目的 SenseVoice 本地转写 | 保留为已有环境下的可选路径，不默认下载大模型 |
| 文字稿加来源信息 | 增加规范视频链接、视频 ID、实际取稿方式、状态、原稿哈希和续跑记录 |
| 写入后抽查 | 要求覆盖全部新增正文读回核验；抽查不冒充全文验证 |

逐字稿保留作者表达；“我们的文风”用于说明、速览和交付语气，不用于改写作者口播。新包保留参考来源和 Chubby 的 MIT 许可。

## 包内文件

- `SKILL.md`：豆包工作执行入口。
- `references/extraction.md`：内置取稿、分页和音频转写回退。
- `references/feishu-docs.md`：飞书新建、追加、失败恢复及全文读回。
- `references/document-format.md`：正文格式与元数据契约。
- `scripts/audio_fallback.py`：音频提取与可选本地 SenseVoice 转写。
- `scripts/build_document.py`：原稿保真 Markdown 生成及核验清单。
- `THIRD_PARTY_NOTICES.md`、`licenses/chubbyskills-MIT.txt`：来源及许可。
