# v1.0.1 · 抖音逐字稿存飞书

修复“逐字稿已提取却只交付本地文件”的问题。用户调用本技能存飞书时，完成条件现在是拿到真实飞书文档链接，并读回新增逐字稿全文核对。

- 在没有内置抖音逐字稿工具的豆包工作环境中，明确使用已验证的浏览器会话 + `yt-dlp` + mediakit Cloud ASR 路径；已经拒绝抖音的工具不再反复尝试。
- 音频备用脚本优先调用 `yt-dlp`，支持复用当前浏览器登录态；旧移动分享页解析只作为兼容回退。
- 新增 `publish_feishu.py`，可从已有 `run.json` 和 `transcript.txt` 直接续跑飞书发布与全文读回。创建结果不明时保留状态，阻止盲目重建重复文档。
- 更新安装与使用说明、真实验证记录和来源边界。

2026-09-24 已用一条真实抖音视频完成 142 段、1241 字的取稿、飞书创建和全文读回；新音频脚本对同一视频在线提取成功。30 项离线测试与 Skill 格式验证通过。ASR 结果未经过人工逐字校对；批量与其他转写回退路径仍需按实际环境验证。

下载 `xiaowei-douyin-to-feishu-v1.0.1.zip` 后将整个技能文件夹导入豆包工作。详细步骤见仓库 [README](../README.md) 和 [使用说明](usage.md)。
