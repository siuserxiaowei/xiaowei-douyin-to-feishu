# 逐字稿专业术语复核

本流程用于发现并纠正语音识别中容易出错的专业词和专名。ASR 的声学识别与术语复核是两件事：上下文可以帮助提出候选词，但不能代替音频证据。不得承诺零错字或“百分百准确”。

## 复核范围

从全文和分段时间轴中筛查：

- 行业概念、专业术语、课程/方法名称；
- 品牌、产品、软件、模型、平台和功能名称；
- 人名、机构名、地名、书名及作品名；
- 英文词、缩写、字母数字混合名称、标准/协议编号；
- 数字、百分比、金额、年份、计量单位；
- 语音上相近、但上下文中一个不成立或明显不通顺的词组。

标题和发布文案只能提供语境线索，不能直接证明视频里说了哪个词。已有字幕中的 ASR 置信度（若工具提供）可辅助排序，不能单独作为改词依据。

## 操作步骤

1. **保全原稿**：若输入是 ASR，先逐字复制成 `transcript_asr_raw.txt`，不覆盖原始识别结果。内置工具直接返回文字时，将原始分页结果另行保存，不能把分页文本冒充 ASR。
2. **生成候选表**：逐段检查上面的易错类别，记录原词、时间点或字幕段号、前后语境、候选规范词和为何怀疑。对口语领域不熟悉时，先从稿件自身上下文识别领域，不要套用与视频无关的术语。
3. **查证候选**：依次参考视频中的可见字卡/字幕（若能获取）、对应音频回听、用户提供的术语表、标题和上下文、产品/机构官方资料。可以联网时，专有名称优先用官方页面核实标准拼写。仅靠搜索结果中偶然出现的相似词不够。
4. **分级处理**：
   - **高置信，可改**：音频读音和语境一致，且术语/专名写法有可靠旁证；或音频清楚、上下文明确到只有一种合理听写。仅做局部替换。
   - **中置信，需复听**：语境支持候选，但音频或旁证仍有歧义。回听对应片段；仍不能确认则保留原识别词并标待核实。
   - **低置信，不改**：只有模型猜测、领域常识或相似搜索结果支持。保留 ASR 原文并列入待确认项，不能“按意思改顺”。
5. **保持逐字**：不得删掉重复、语气词、否定词、口误、自我修正或不完整句；不得重排句子、补全省略、润色表达。断句和标点可为阅读微调，但不能改变词序或含义。普通词不能仅因“不像专业表达”就改成术语。
6. **写复核记录**：生成 `term_review.json`，记录稿件哈希、复核状态、采用术语表、每个已修改/未确认候选的时间点、ASR 原词、候选词、最终处理、证据来源和置信度。没有候选时也记录 `candidates: []`，状态为 `reviewed_no_changes`；如果没有回听或无法查证，则如实降低状态，不声称已验证音频。
7. **同步最终稿**：将已确认的局部修订写入 `transcript.txt`，原始版保留不动。重新计算最终稿的 UTF-8 SHA-256 与字符数，更新 `run.json` 现有的 `transcript_sha256`、`transcript_characters` 字段；同时记下术语复核状态和 `term_review.json` 路径。发布飞书前先确认脚本读取的是修订后的 `transcript.txt`，哈希与字数一致。

## 记录格式

```json
{
  "review_status": "reviewed_with_audio",
  "transcript_raw_file": "transcript_asr_raw.txt",
  "transcript_final_file": "transcript.txt",
  "glossary": null,
  "candidates": [
    {
      "segment": 18,
      "time": "00:42.1-00:45.8",
      "context": "前后语境的短摘录",
      "asr_text": "原识别词",
      "candidate": "候选规范词",
      "decision": "corrected",
      "confidence": "high",
      "evidence": ["对应时间点音频回听", "产品官方名称页面"],
      "reason": "读音与上下文吻合，官方拼写一致"
    }
  ]
}
```

`review_status` 使用 `reviewed_with_audio`（有对应音频复听）、`reviewed_with_sources`（有可靠文字旁证但未复听）、`reviewed_no_changes`（检查后没有待修项目）、`needs_review`（仍有未确认项）或 `not_reviewed`。`decision` 使用 `corrected`、`kept_unverified`、`not_a_term`。不要把候选表整段塞进逐字稿；用户需要时可在逐字稿之后简短列出未确认项。只有用户提供或明确确认的术语才可作为以后任务的固定术语表。
